## Technical Conventions
- Missing, blank, retired, or invalid `MASTRA_RUNTIME_MODE` values normalize to `default`; startup freezes that mode before creating runtime resources, and `default` requires a persisted passing production `MASTRA_PROMOTION_ARTIFACT`. Use explicit `limited` for constrained rollout.
- External parsers that write artifacts must pass an artifact root/byte quota to `runBoundedProcess` and revalidate the complete output tree before reading a selected artifact; raw image/base64/provider fields stay inside the temporary workspace.
- Raw-file ingestion uses `application/octet-stream` as transport and `x-file-mime-type` for the file's actual MIME; parser subprocesses use `shell: false`, isolated temp workspaces, byte/time limits, cancellation, and bounded head plus ring-tail diagnostics.
- File source identity uses absolute canonical paths; Windows paths are case-normalized. CLI submits its raw path as a legacy alias so upgraded relative-path histories can be adopted without globally reinterpreting JSON external IDs.
- `EMBEDDING_DIMENSIONS` must match the Elasticsearch dense-vector mapping and is validated as a positive integer.
- This repository uses `tickets.md` as its local issue tracker when no Git remote is configured; agent-ready specifications use the `ready-for-agent` marker.
- Ticket 24 delivery order is Wave 0 reliability/deep seams, then L1/L2, L3, L4, L5, L6, L7, query tracing, and runtime/release closure; each wave must pass its own acceptance gate before downstream work starts.
- Tests that assert on `doneEvent.result.status === "completed"` must use a mock model that produces `[cite:ID]` citations matching known Evidence IDs — the `referencesForReply` gate (evidence.ts) returns `[]` for answers with no citations, triggering `insufficient_evidence` terminal instead of `completed`. Use a `modelWithCitations(results)` helper that calls `buildEvidence(results)` to compute stable Evidence IDs and yields `answer [cite:ev_...]`. Tests that only assert on loop/retrieval metadata (not terminal status) can use the plain `"answer"` mock model.
